# 官方 RAG 教程阅读笔记
1. **2-Step RAG 是什么**：检索总在生成之前执行，先将用户的查询向量化并在知识库中检索出相关的上下文，然后将上下文与问题一起拼接成提示词发给大模型生成答案。它的特点是简单、可预测、延迟低。
2. **C3 做了什么**：llm-universe的C3章节主要讲解了“搭建知识库”的基础。包括词向量与Embedding的概念、数据的读取清洗与切片处理，以及如何搭建和使用向量数据库。
3. **C4 做了什么**：C4章节主要讲解了“构建RAG应用”。包括将大模型接入LangChain、基于LangChain搭建检索问答链，以及最终通过Streamlit将知识库助手部署为可交互的Web应用。

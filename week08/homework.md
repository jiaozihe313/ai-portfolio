# W8 课后作业提交

## 一、200字反思：README为什么要诚实写“已知问题”？

在 README 中诚实写明“已知问题”，是专业工程师的基本素养。技术产品不可能完美，主动披露限制（如本地模型未启动会报错、特定语料下检索偏移等），不仅能极大降低使用者的排雷成本，避免因“踩坑”产生挫败感，更能体现开发者对产品边界的清晰认知。反之，隐藏问题等同于埋雷，一旦爆发会严重透支项目的信任度。诚实的文档不仅是写给用户看的，也是给未来的自己留的避坑指南。

## 二、预习 W9：希望助手拥有的 2 个工具

**工具 1：生词表检索工具**
- **输入**：一个中文词语（如“把字句”）
- **输出**：该词的拼音、词性、HSK 等级及释义。

**工具 2：HSK 分数计算器**
- **输入**：听力答对数、阅读答对数、写作分数
- **输出**：按 HSK 评分标准算出的总分，以及是否通过该级别。

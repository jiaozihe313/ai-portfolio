# M1 会话协议草案

## ① 事件类型与字段

所有会话事件统一为一条 JSON 记录，核心字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| session_id | string | 会话唯一标识 |
| seq | int | 事件序号，会话内单调递增 |
| ts | int | 事件时间戳（毫秒） |
| type | string | 事件类型（audio / text / tool_call / state） |
| payload | object | 事件负载，随 type 变化 |

## ② 状态机

idle → listening → thinking → tool_calling → speaking → idle

- idle：空闲，等待输入
- listening：接收用户输入（语音 / 文字）
- thinking：模型思考
- tool_calling：调用外部工具（如 MCP 工具）
- speaking：输出回复
- 打断回退：speaking 中收到新输入，立即回退到 listening 重新处理

## ③ 权威与幂等

- 服务端为唯一权威：一切状态以服务端记录为准，客户端只做展示与提交
- 幂等：服务端按 seq 去重，同一 seq 的事件重复到达只处理一次

## ④ 断线语义

- 客户端断线重连后，携带本地最后收到的 seq 向服务端发起补发
- 服务端将该 seq 之后的事件按序补发，保证不丢、不重

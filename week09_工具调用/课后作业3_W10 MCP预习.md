W10预习作业：概念辨析与MCP期待工具

一、概念辨析（三句话）
1. Function Calling（模型侧机制）：是 AI 模型自己的“决策机制”，模型在对话中决定何时调用工具、调用哪个工具，并输出对应的参数。
2. MCP（工具侧协议）：是提供工具那一方的“标准接口规范”，让不同来源的外部工具（如数据库、GitHub等）能以统一的格式被 AI 模型接入。
3. 普通 API 调用：是程序员写死在代码里的“固定连接”，（比如之前的 if use_rag == True），缺乏 AI 模型自主决策的灵活性。

二、我期待 MCP 接上的 2 个外部工具
1. 学校教务系统接口（自动查询成绩和课表）。
2. 网页搜索工具（让 AI 能实时查询最新的国际中文教学资讯）。

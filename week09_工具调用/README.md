# W9 学生代码包 · 工具调用（tool_agent.py）

本包是第 9 周「智能体原理：让 AI 决定下一步做什么」的课堂骨架，与讲义中的代码块完全一致。
核心文件只有一个：`week09_工具调用/tool_agent.py`（约 150 行，不依赖任何框架）。

## 运行四步

1. **解压**：把整个文件夹解压到你的工作目录（建议放进你作品集仓库的骨架根目录下，
   与 `week08_助手v1.0` 等目录平级；单独放在一个新文件夹里也能跑）。
2. **装依赖**（本周只需这两个）：
   ```
   pip install openai python-dotenv
   ```
3. **配密钥**：把 `.env.example` 复制一份并重命名为 `.env`，填入你的
   `DEEPSEEK_API_KEY`。**`.env` 绝不提交进仓库（一票否决）**。
4. **运行**：进入 `week09_工具调用` 目录执行
   ```
   python tool_agent.py
   ```
   不带参数会跑一条复合问句（查"把"的 HSK 等级 + 当前时间）；
   也可以自带问题：`python tool_agent.py 帮我算一下 35*24 等于多少`

> `weekpath.py` 与 `data/` 是骨架的公共依赖（跨周导入、数据路径、.env 加载、生词表），
> 已一并放进本包。如果你的骨架里已有同名文件，覆盖即可，内容兼容。

## 三个工具

| 工具 | 输入 | 输出 | 说明 |
|------|------|------|------|
| `get_time` | 无参数 | 当前时间 | 让模型"知道现在" |
| `calc` | 算式字符串，如 `'35*24'` | 计算结果 | 白名单 AST 安全计算，**绝不裸 eval** |
| `hsk_level` | 生词，如 `'把'` | HSK 等级 | 查 `data/生词表.csv`，确定数据靠查表不靠模型记 |

循环机制：模型输出一行 JSON `{"tool": "工具名", "args": [...]}` → `parse_calls` 容错解析
（能兜住围栏、客套话、多调用并列）→ 执行 → 结果回喂 → 模型据此作答；最多 `max_calls=2` 轮防失控。

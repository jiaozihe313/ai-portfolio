# W2 提示词模板库 (Prompt Library)

## 模板 1：针对特定词汇生成语境对话
- **提示词**：你是一位国际中文教师。请用“商量、决定、坚持”这三个词，编写一段发生在中国留学生和房东之间的日常对话。对话要自然，长度约150字。
- **适用说明**：用于HSK4级词汇的语境化教学，帮助学生在真实场景中理解词义。

## 模板 2：学生作文语法纠错与评语
- **提示词**：你是一位经验丰富的汉语老师。请批改以下这段外国学生的作文，指出其中的语法错误（如“把”字句误用），并用鼓励的语气给出3条修改建议。作文内容：[粘贴内容]。
- **适用说明**：用于中级写作课的课后作业批改辅助。

## 模板 3：HSK阅读题出题助手
- **提示词**：请模仿HSK4级阅读真题的风格，根据《愚公移山》的故事背景，出1道单选题和1道判断题。请给出四个选项，并附带答案和详细解析。
- **适用说明**：用于教师快速生成测试题或练习材料。

## 模板 4：跨文化交际案例分析
- **提示词**：请列出3个中国人在交际中常让外国人感到困惑的习惯（例如：过度关心隐私、委婉拒绝），并给出针对外国学习者的文化解释和应对建议。
- **适用说明**：用于口语课或国情课上的文化探讨环节。

## 模板 5：语法点对比教案生成
- **提示词**：请对比“如何”和“怎么”这两个疑问词在用法上的区别。用表格形式列出它们在正式程度、适用场景和语法结构上的不同，并各给2个例句。
- **适用说明**：用于课前备课，快速理清易混淆语法点。

## 模板 6：角色扮演口语话题设计
- **提示词**：设计一个“在饭馆点餐遇到上错菜”的交际场景。请给出学生A（顾客）和学生B（服务员）的角色卡，并列出该场景必须用到的5个目标词汇。
- **适用说明**：用于口语课的小组互动环节。
